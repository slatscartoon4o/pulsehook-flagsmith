Webhook SDK · Quickstart

Get your first webhook delivered
in under two minutes.

PulseHook delivers signed, retry-safe webhooks. This page is the exact quickstart developers land on — how it works depends on the variant you were assigned.

  • 1 endpoint

Three steps to a delivered event

Copy each block into your own project and run it. No account needed for this sandbox.

  1. 1

    Install the SDK

    One dependency, no transitive baggage.

    shell 
    npm install @pulsehook/sdk
  2. 2

    Point it at your endpoint

    The signing secret is printed once, on first delivery.

    javascript 
    import { PulseHook } from '@pulsehook/sdk';

const hook = new PulseHook({
  endpoint: 'https://api.yourapp.dev/webhooks/pulse',
  events: ['delivery.succeeded', 'delivery.failed'],
});
  3. 3

    Send a test event

    You should see a delivered receipt within a second.

    javascript 
    await hook.send({
  event: 'delivery.succeeded',
  data: { order_id: 'ord_1042' },
});

What happens under the hood

    

      

        
Signed payloads

        
Every delivery carries an HMAC-SHA256 signature so you can verify it came from us.

      

      

        
Retry with backoff

        
Non-2xx responses retry at 1s, 5s and 30s, then land in a dead-letter queue you can replay.

      

      

        
Idempotent by design

        
Each delivery has a delivery_id. Deduplicate on it and you're safe to retry anything.
